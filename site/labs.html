Every method error found while building the instrument, what the measurement was, and what changed because of it.

The instrument has been wrong eleven times. This is the list.

  1. IThe hash that could not be reproduced
  2. IIThe classifier was reading the address bar

Five of the first six findings have the same shape: the rule existed, and no line of code enforced it. That is the lesson the whole project now runs on — a rule that cannot stop a run is a wish.

600 STATES turns one UTC day of observed news into one image. Six hundred observations, each read through a frozen emotional protocol, each converted to a colour by a frozen formula, laid out in the order they happened across a 30 × 20 field. Nothing is composed. No colour is chosen. If a day comes out ugly, the day came out ugly.

That is an easy thing to claim and a hard thing to be true. So this page is the audit — including the findings that made finished work worthless.

I

The hash that could not be reproduced

7 September 2026

Every row of every manifest carries a SHA‑256 so that anyone can recompute it and confirm nothing was altered. The documented formula said: compact JSON, sorted keys, empty values as null.

That formula produced zero matches on every manifest we had. We tried roughly two hundred variants — with and without sorted keys, compact and spaced, four treatments of empty values, four column subsets. Nothing.

Rows reproducing under the documented formula
Manifest generationRowsReproduces
v2.25,4005,400

The real rule turned out to be pipe‑joining in column order. But that was not the serious part. This was: the newer, nominally authoritative freeze could not be verified at all — under any canonicalisation. The older generation was provable; its successor was not.

The rule now lives in code, not in prose. Prose cannot be executed.

II

The classifier was reading the address bar

8 September 2026

The model classifies one string per observation: the headline, as the publisher wrote it. When we built the page that would show a tile’s news behind its colour, we checked where those strings had actually come from.

303 of 600 were not headlines. They were words scraped out of the article’s URL. Twenty‑four observations had no readable text at all — an address with no words in it, article70456163. Those tiles had been classified on nothing.

The cause was ordering. Evidence capture fetches the page, and the page carries the headline — but evidence capture ran after selection and classification. The step that produced the input ran after the step that consumed it.

A URL slug that reads like a headline is perfect camouflage.

“Kingston higgler charged with murder” looks like a headline. It is not. One count — how many of the 600 came from a page title — would have exposed it in a second. Nobody ran the count.

Evidence capture now runs first, and every row carries claim_source. Measured after the fix, on a live day: 542 of 600 from the publisher’s own page title.

III

The manifest named a source it had never read

9 September 2026

Every row of every manifest declared registry_version = v2.0 — a source registry of 107 publications. The code that decides which news can become an observation was reading a different file: 75 publications.

The 32 domains added in September, weighted deliberately toward the parts of the world where the candidate pool was thinnest, had never appeared in any candidate pool at all. With the correct registry the pool grows by about sixty per cent. That is not a rounding difference. It is a different set of possible observations, and therefore a different artwork.

Four finished works declared a source they were not built on. For a project whose entire thesis is the manifest is the Proof of Work, there is no worse defect. They were discarded.

It surfaced only because the code was moved to another machine, where a hardcoded path did not exist and the program crashed. On the original computer the file was still sitting there and everything appeared to work.

A path that happens to exist is not the same as a path that is right.

IV

The check that could not fail

November 2026

The audit script runs nineteen checks over a finished state and prints ALLT STAMMER — everything holds — when they pass.

One of them passed a hardcoded True into the comparison. It had never been capable of failing. It was not a weak check; it was the shape of a check with nothing inside it.

It is now a measurement that reports a real number: 94.3% of observations carry a content hash of the page as fetched. The rest are 403s, 404s and paywalls. The figure is printed as a measurement and not as a pass, because the floor has not been decided — and an undecided floor must not be dressed up as an approval.

V

The model invented a row to make the numbers work

5 November 2026

The execution spec says fifty observations per batch. The code said sixty, hardcoded in two places, neither of them reading the spec.

At sixty rows, this happened: the model lost one observation, noticed the count was wrong, and filled the gap.

{"observation_id": "OBS-911C93E58B2399D5-DUP",
 "neutral_event_representation": "Placeholder not applicable.",
 "scores": {"Joy": 0.00, ... all sixteen zero},
 "classification_note": "No content supplied for this slot."}

Sixteen zeroes is precisely the defect that invalidated the pilot series.

The batch size is now read from the frozen spec and appears in no source file. A test fails if a literal number ever returns to the batching code.

VI

Sixteen characters with no redundancy

6 November 2026

In the first full run, eleven of eighteen failed attempts were ID errors — sixty‑one per cent, the dominant failure mode by a wide margin.

An observation_id is OBS- plus sixteen random hex characters. It is the only part of the output that carries zero information and zero redundancy. Everything else the model can self‑correct: a mistyped headline reads wrong, a bad score shows against the other fifteen. In a hash string there is nothing to constrain the next character, so OBS-D8238B561030425F looks exactly as plausible as the real one. There is nothing to notice the error against.

The obvious fix would be to verify the row against its content and restore the ID. We measured that idea on 1,750 known‑correct rows before building it:

Word overlap between input headline and model output
Correct pairsdown to 0.000
Random pairsup to 0.700
Simulated dropped rowcould score higher than the original

No threshold separates the distributions. That check would have looked like a check without being one — the same defect as finding IV. It was rejected, and that matters as much as a fix.

What works instead requires no threshold at all. If exactly one requested ID is missing and exactly one unknown ID is present, the other forty‑nine are exact matches, so there is only one observation the row can be. Logic, not similarity. Two unknowns, a duplicate, or a wrong row count, and nothing is touched.

VII

A band that was never a rule

6 November 2026

Before changing models you must prove the new one follows the protocol. We wrote that gate, and it required each row to carry 13–15 authored scores out of 16.

That number came from a sentence in an internal handover describing how the pilot’s classifier had behaved. A description had been promoted to a rule. It excluded a model that follows the protocol perfectly well.

Measured on the reference model’s own 600 rows: the eight lowest scores in a row are exactly 0.00 in 33.8% of cases, median 0.020. The reference model zeroes a third of its own tail. The band was measuring the granularity of the tail, not whether the model does the work.

The gate is now derived from the spec’s own mandatory fields. Nothing else gets to become a rule by being observed once.

VIII

Seven values out of a hundred and one

6 November 2026

The question that found this one was simple: the vendor’s own description of their smallest model lists classification as its purpose. So why doesn’t it qualify?

The spec forbids quantizing intensity and confidence. The prompt says it in plain words: “Do not quantize confidence to a small preferred set of values.” Nothing tested it. The model passed the gate.

150 values per model — share sitting on the 0.05 grid
Modelintensityconfidence
Opus 513%20%
Sonnet 5.551%30%
Haiku 5.5100%100%

Its confidence used seven distinct values across 150 rows: 0.55, 0.60, 0.70, 0.75, 0.80, 0.85, 0.90. The spec grants two decimals — 101 available values. Chance would put about 21% on that grid. 150 out of 150 is not chance. It is a preferred set, which is the exact thing the prompt forbids.

The number had already been seen, and written down as “close to the spec’s prohibition — reported, not gated, but material.” Writing that something is close to a prohibition and then letting it through is how a rule becomes a wish with a footnote.

The new gate has no threshold, deliberately. The question is not how many values but any at all: does the model use the precision the spec gives it, or does every single value sit on a coarser grid? One value off the grid is enough to pass.

The small model is genuinely good at classification in the ordinary sense — choose one label from a set. This instrument does something else: it writes eighteen continuous numbers, and the label is derived afterwards from whichever is highest.

Choosing and measuring are not the same task.

IX

The instrument does not reproduce itself

6 November 2026 — and this is the one that matters

To choose a model you need a reference to compare against. Ours was a manifest the reference model had produced earlier. We had never run the reference model against its own reference, because a reference is a fixed point.

It cost $1.29 to check. It is not a fixed point.

Same model, same day, same frozen prompt
Primary states matching the reference42 of 50
Colour difference — median · p90 · max0.66 · 25.15 · 69.01
Scaled to a full 600‑tile work~170 visibly different, ~110 a different colour entirely

Read the same day again and eight tiles in fifty change their primary emotional state. About one tile in ten moves to a colour that is not a shade of the old one.

Nothing is broken. This cannot be engineered away. It is a property of reading the world with a language model, and any other method that reads six hundred news items and assigns them emotional states — a human included — would do the same.

But our language had implied more than existed, and the difference has to be written down.

True, and proven: a frozen manifest always produces exactly the same image. Verified on a full day: 600 of 600 colours reproduced, master 3087 × 2057 pixels. The render is arithmetic. No model is involved in that step.

Not true: that the same day would always produce the same manifest.

So the irreversibility begins at the freeze, not at the day:

Each state is one reading, not the only possible one. Run the same day through the instrument again and some tiles fall differently. The instrument does not hide this.

What is fixed is the freeze. Once the manifest is sealed and hashed, the image follows from it by arithmetic alone — identically, forever. The day is observed once. The reading is made once. The freeze is what makes it a work.

Two things we will not say. The variation does not mean anything — it is sampling variance in a language model, not an expression of the day’s ambiguity, and claiming otherwise would be exactly the kind of assertion this instrument exists to avoid. And this was not the plan all along. It was measured on 6 November 2026 and described afterwards. Measurement first, meaning second — in that order, always.

X

One day, one run, one outcome

6 November 2026

Finding IX is only honest while the run is the first one. If a day can be re‑run until the picture looks good, there is no answer to why this reading and not another — and then irreversible is a word with nothing behind it.

So it is now a gate, in both places a day could have been redone. New calls against a frozen day are refused. The freeze never overwrites a freeze. Retrying a single batch that failed validation is unchanged — that completes a run, it does not redo one.

No flag opens it. Redoing a day requires deleting the lock file by hand: a visible, deliberate act that no scheduled job performs by accident. And the run journal grows and is never overwritten, so the number of calls made for a day is publishable evidence that the rule was kept.

•

Could a state ever look like something?

People ask whether a day will come out looking like a face, a figure, a shape. The honest answer is yes, and essentially never — and the two halves of that sentence are worth separating, because it is easy to give the wrong one.

Nothing in the process builds shapes. The grid is ordered by time, not by space. Two horizontally adjacent tiles are about two minutes apart; two vertically adjacent tiles are about seventy‑two minutes apart. Adjacency sideways is strong, vertically almost nothing, and a figure needs both. On a measured day, 504 of the 600 colours were unique — the field is made of single tiles, not blocks.

But nothing excludes it either. The output space contains every possible assignment of six hundred colours to six hundred positions, and a recognisable figure is somewhere in that space. It is not forbidden. It is merely absurd — roughly 1 in 10300. One work a day since the Big Bang would give about 5 × 1012 attempts. You would need some 10287 universes’ worth of days.

What can appear is temporal. A large story produces many observations close together in time, and those sit side by side. The day’s dominant event shows up as a horizontal run. A stripe, not a face.

The instrument does not draw. It records. So for a state to look like something, the world would have had to have a day shaped like that something.

You are welcome to see things in it anyway. People see things in clouds. Just know that it is you, not us — and that a day is never chosen for how it looks.

•

Still open

Honest work has an open list, and this is ours.

  • Temperature. Not set in the code, not in the spec, never logged. Unset means the vendor’s default applies — a value nobody owns and that can change with a model version. The run journal records it as unmeasured. It must be measured, not guessed. The November calibration measured model choice, not temperature, and that is the one promised measurement that did not happen.
  • The floor for evidence with a content hash. 94.3% measured. Which floor should apply is undecided, so the number is reported and not approved.
  • Secondary states are less stable than primary. 0.56 against 0.78 in self‑agreement. Whether the colour model should weight secondary lower is open — and must not be decided on the basis of which option looks better.
  • The reach of the one‑run rule. The gate stops a re‑run of a frozen day, but deleting the lock file by hand leaves no trace inside that day’s own folder. An append‑only freeze log outside it is proposed and not yet built.
  • Two protocols have no code at all — reflection and macro‑state naming.

Every entry above cost something.

Four finished works were thrown away. Weeks went into a hash formula that was documented wrong. A gate we were proud of turned out to be incapable of failing.

None of it is hidden, because the alternative is worse. A series that claims to be a traceable document of a day, and quietly papers over the days it got wrong, is not a document. It is decoration with a story attached.

Measure, don’t assert. A sample that looks reasonable is not a measurement.

A rule that cannot stop a run is a wish.

One definition, one place. Two definitions of the same thing drift apart.

Every derived field carries its derivation.

A failed call must leave as much trace as a successful one.

A rejected solution is documented as carefully as an adopted one.

You may write down what is already true. You may not invent what nobody measured.

The series starts on 1 December 2026. One work per UTC day, for as long as there are days.
